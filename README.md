# Smart Traffic Management & Pedestrian Safety System

## Overview
An Arduino-based traffic management simulation designed to demonstrate traffic signal automation and pedestrian safety using electronic components and embedded programming.

## Objectives
- Simulate automated vehicle traffic signals.
- Provide dedicated pedestrian WALK and STOP indicators.
- Allow pedestrians to request a crossing using a pushbutton.
- Generate audio alerts using a buzzer.
- Display traffic and pedestrian status on a 16×2 LCD.

## Components Used
- Arduino Uno
- Red, yellow and green LEDs
- Pedestrian WALK and STOP LEDs
- Pushbutton
- Piezo buzzer
- 16×2 LCD
- 10k potentiometer
- 220Ω resistors
- Breadboard and jumper wires

## Technologies
- Arduino IDE / Embedded C++
- Tinkercad Circuits
- Digital input/output
- LCD interfacing
- Electronics and circuit simulation

## Working Principle
The Arduino controls the vehicle traffic lights and pedestrian indicators according to programmed timing sequences. A pushbutton allows a pedestrian crossing request during the vehicle-green phase. The system then changes the vehicle signal to yellow and red before activating the pedestrian WALK indicator. A buzzer provides an audio alert, while the LCD displays the current signal status.

- Understanding basic automation and control logic.
- Practising circuit design and debugging.
